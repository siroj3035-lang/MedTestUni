# МедТест — сайт тестов модуля для студентов-медиков

Как это устроено:
- **Сайт** — два файла (`index.html`, `config.js`). Выкладывается бесплатно на GitHub Pages.
- **Сервер и база данных** — Supabase (бесплатный тариф). Вся серверная логика (регистрация по логину и паролю, проверка ответов, статистика, права администратора) лежит в одном файле `supabase/schema.sql`.
- Почта нигде не нужна: вход только по логину и паролю.
- Правильные ответы хранятся в базе и в браузер **не отправляются**, проверка идёт на стороне базы данных.

## Запуск (около 15 минут)

### 1. База данных в Supabase
1. Зайдите на supabase.com, создайте проект (New project) и запомните пароль базы.
2. Откройте **SQL Editor → New query**, вставьте весь текст файла `supabase/schema.sql` и нажмите **Run**. Должно появиться «Success».
3. Откройте **Project Settings → API Keys** (или кнопку **Connect** сверху) и скопируйте:
   - **Project URL** (вида `https://xxxx.supabase.co`);
   - **Publishable key** (начинается с `sb_publishable_`; в старых проектах это ключ `anon`).
4. Вставьте их в файл `config.js`. Эти два значения не секретные, их можно хранить в репозитории. **Секретный ключ (`secret` или `service_role`) в сайт вставлять нельзя.**

### 2. Сайт на GitHub Pages
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки (кнопка **Add file → Upload files**).
2. Откройте **Settings → Pages**, в разделе *Build and deployment* выберите **Deploy from a branch**, ветка **main**, папка **/(root)**, нажмите **Save**.
3. Через минуту сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Этой ссылкой можно делиться со студентами.

### 3. Первый вход
**Первый зарегистрированный аккаунт автоматически становится администратором.** Поэтому сразу после запуска зарегистрируйтесь сами, до того как разошлёте ссылку. У администратора в меню появится вкладка **«Админ»**.

## Как добавлять тесты
Вкладка **Админ** → выберите предмет, язык, курс, введите тему и вставьте вопросы в таком виде:

```
Какой вид некроза характерен для инфаркта миокарда?
- Колликвационный
+ Коагуляционный
- Казеозный

Ситуация: Мужчина 58 лет, боль за грудиной 3 часа.
Какие изменения ожидаются через сутки?
+ Очаг коагуляционного некроза
- Казеозный некроз
```

- Вопросы разделяются пустой строкой.
- `+` отмечает единственный правильный вариант, `-` остальные (от 2 до 6 вариантов).
- Вопрос со словом «Ситуация:» в начале становится ситуационным, остальные тестовыми.
- Кнопка **«Проверить»** покажет, сколько вопросов распознано и где ошибки, **«Загрузить в сайт»** добавит их.
- Узбекская версия темы добавляется так же: выберите язык «O‘zbekcha» и укажите то же название темы.
- Ниже можно просмотреть вопросы темы, удалить вопрос или всю тему.

## Полезные операции (SQL Editor в Supabase)
Сделать пользователя администратором:
```sql
update app.users set is_admin = true where login = 'логин';
```
Сбросить пароль студента, который его забыл:
```sql
update app.users set pass_hash = extensions.crypt('новый_пароль', extensions.gen_salt('bf', 10)) where login = 'логин';
```
Посмотреть, сколько зарегистрировано пользователей:
```sql
select count(*) from app.users;
```

## Безопасность
- Пароли хранятся только в виде хэшей bcrypt.
- Таблицы закрыты от прямого доступа из браузера; доступны только функции `api_*`, и каждая проверяет вход по токену.
- После 5 неверных паролей подряд вход блокируется на 10 минут.
- Права администратора проверяются на стороне базы, поэтому обойти их через код сайта нельзя.
- Бесплатный проект Supabase может приостанавливаться при долгом отсутствии посетителей; его можно возобновить одной кнопкой в панели Supabase.
